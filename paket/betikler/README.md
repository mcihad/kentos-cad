# betikler — örnek Python betikleri

Kurulumda `<kaynak>/betikler/` olur (CLAUDE.md §26): KentOS ile gelen, Python konsolunda ya da `kentos` kütüphanesiyle
çalışan örnek betikler. Kullanıcının kendi betikleri `kentos-cad/betikler` klasöründedir.

Python ile yeni bir İşlemler aracı yazmak için betik değil eklenti kullanılır: örneği
`paket/eklentiler/ornek-isleme/`dadır.
