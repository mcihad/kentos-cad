# Pafta düzeni (sheet)

Model alanından kâğıda: ölçekli harita çerçeveleri, karelaj, antet, lejant, ölçek çubuğu, kuzey
oku, tablolar, koordinat listesi, ana sayfalar, atlas ve şablon kitaplığı. Şablonlar sistemle gelir
ya da kullanıcı oluşturur; kullanıcı şablonları buluta eşitlenir ve paylaşılır. Web ve masaüstünde
aynı Rust çekirdeğiyle çalışır.
