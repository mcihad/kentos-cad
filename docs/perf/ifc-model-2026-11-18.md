(16 Kasım 2026, aynı makine).

## Ortam

- **Makine:** Apple M5 (10 çekirdek), 32 GB, macOS 27.2.1.
- **Derleme:** release (lto thin), rustc 1.100.0; commit `13b25c654` ve bu dilimin değişiklikleri. Python 3.15.1 (formun
  süresi süreç başlangıcıyla).
- **Ölçüm:** başka ağır süreç yokken, tek koşu.

```text
KENTOS_PERF_FLATS=1,20,100 cargo test --release -p kentos-headless --test headless ifc_timing -- --ignored --nocapture
```

## Veri

Kabul akışının 2+1 dairesi onarlı satırlarla çoğaltılmış (`flat_timing`), çizelgeler bir kez. Bütün daireler tek katta:
100 dairede 500 mahal aynı katta.

## Bütçe (bu makinede, release)

- Denetim ya da kalite formu istenince pencerenin iş parçacığı: okuma kopyası, ≤ 1 ms (100 dairede 0,08 ms).
- Model eşlemesi (kuralın iş parçacığında): 20 dairede ≤ 50 ms, 100 dairede ≤ 300 ms.
- Denetim'in Dijital proje cevabı (eşleme, yazma, geri okuma ve olgular, form): 100 dairede ≤ 1 s (bugün ~0,63 s).
